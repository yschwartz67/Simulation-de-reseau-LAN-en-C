# Projet à bas niveau simulant un réseau LAN

# Description

Ce projet est une simulation d'un réseau LAN crée sur Visual Studio Code en C et permet d'avoir des informations sur un réseau LAN ainsi que de gérer ce réseau.

# Installation du projet

Avant de continuer, pour pouvoir lancer le programme il faudra être sur Linux.

1. Télécharger le fichier .zip dans Release
2. Dézipper le fichier .zip
3. Aller dans le fichier dézipper , faire un clique droit dans ce dossier puis cliquer sur "Ouvrir dans un terminal"
4. Taper la commande ```make``` puis ```./bin/network [nom_du_fichier_texte].txt```

# Fonctionnalités du projet
- Affichage du réseau
- Activation / Désactivation du protocole STP
- Envoi d'une trame ethernet
